# Task 2 – Library Book Inventory Management System

## Week 2 – Java Application Development

### Objective
Develop a command-line Java application to manage a library book inventory using CRUD operations.

### Features
- Add Book
- List All Books
- Update Book
- Delete Book
- Exit

### Book Details
- Book ID
- Title
- Author
- ISBN
- Publication Year

### Technologies Used
- Java JDK 8+
- ArrayList
- Scanner
- Exception Handling

### Storage
All book data is stored in memory using ArrayList<Book>.
No database or external framework is used.

### Project Structure

LibraryBookInventory/
- src/Book.java
- src/LibraryApp.java
- README.md
- screenshots/

### Validation
The application validates user input, prevents duplicate Book IDs and ISBNs, and handles invalid input using exception handling.

### Testing
The application was tested for adding, listing, updating and deleting books, duplicate ISBN handling, invalid input, and non-existent Book IDs.
